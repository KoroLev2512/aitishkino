# ADR 0005: Многоуровневая стратегия тестирования (Vitest + Playwright + Axe)

## Статус

Принято (Accepted)

## Контекст

В исходном проекте тесты полностью отсутствовали (`npm test` выдавал ошибку отсутствия скрипта), что не позволяло гарантировать работоспособность приложения при рефакторинге и зависимостях, а также не соответствовало стандартам Senior / Lead Frontend инженерии.

## Решение

Внедрена трехуровневая пирамида тестирования:

### 1. Модульные тесты (Unit Tests) — Vitest

- **Сфера**: Чистые функции, схемы валидации, генерация карты сайта.
- **Примеры**:
  - `src/lib/validations/lead.test.ts`: тестирование позитивных и граничных сценариев Zod-схемы (валидный номер телефона РФ, опциональный email, honeypot, отказ от согласия 152-ФЗ).
  - `src/app/sitemap.test.ts`: проверка наличия всех канонических URL-адресов в XML-карте сайта.

### 2. Компонентные интеграционные тесты — React Testing Library + Vitest (JSDOM)

- **Сфера**: Поведение компонентов в изоляции с симуляцией действий пользователя (`@testing-library/user-event`).
- **Примеры**:
  - `ConsultationSection.test.tsx`: рендеринг формы, валидация полей, перехват сабмита с моком `submitLead`, обработка сетевых ошибок, экран успеха.
  - `FAQItem.test.tsx`: доступность аккордеона, переключение состояний `aria-expanded` и связка `aria-controls` с `id` панели ответа.
  - `LoginForm.test.tsx`: тестирование интерактивной формы авторизации (переключение ролей «Я ученик» / «Я родитель», способы входа по SMS и паролю, маска телефона, валидация полей, переключение видимости пароля).

### 3. Сквозные и доступностные тесты (E2E & Accessibility) — Playwright + Axe

- **Сфера**: Тестирование продакшн-сборки (`out/`), запущенной на локальном сервере.
- **Файл**: `e2e/smoke.spec.ts`.
- **Проверки**:
  - Загрузка главной страницы, наличие ровно одного заголовка `h1` и ключевых секций.
  - Навигация по страницам курсов, политики конфиденциальности и страницы авторизации `/login`.
  - Взаимодействие с формой в реальном браузере Chromium.
  - Автоматизированный аудит доступности страниц (`/`, `/courses/python`, `/login`) через `@axe-core/playwright` по стандартам WCAG 2.1 Level A & AA (требование: 0 критических и серьезных нарушений).

## Последствия

### Преимущества

1. Запуск unit/компонентных тестов занимает **1.1 секунды**, предоставляя мгновенную обратную связь разработчику.
2. E2E тесты Playwright запускаются за **4 секунды** на реальных статических артефактах сборки.
3. Автоматизированные тесты интегрированы в GitHub Actions CI, блокируя мерж любых регрессий.
