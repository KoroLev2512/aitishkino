# ADR 0001: Использование статического экспорта Next.js (`output: 'export'`)

## Статус

Принято (Accepted)

## Контекст

Проект «Айтишкино» представляет собой маркетинговый лендинг и страницы образовательных курсов детской школы программирования и робототехники. Основные требования к приложению:

- Максимальная скорость загрузки (Time To First Byte < 50 мс, First Contentful Paint < 0.8 с) по всей территории РФ и мира;
- Высочайшая отказоустойчивость при пиковых нагрузках (запуск рекламных кампаний, сезонные наборы);
- Минимальная стоимость и сложность инфраструктурной поддержки (отсутствие необходимости поддерживать Node.js runtime серверы или Kubernetes-кластеры);
- Возможность хостинга на любом глобальном CDN (Vercel, Cloudflare Pages, GitHub Pages, Nginx, S3/Cloud Storage).

## Решение

В конфигурации `next.config.ts` зафиксирован режим:

```ts
output: 'export';
```

Все страницы (`/`, `/courses/python`, `/privacy`, `404`), а также SEO-артефакты (`sitemap.xml`, `robots.txt`) компилируются в чисто статическую HTML/CSS/JS директорию `out/` на этапе сборки (`npm run build`).

Все динамические взаимодействия (отправка заявок, клиентская валидация, раскрывающиеся списки FAQ, переключение программ курсов) реализованы на клиенте с изоляцией через абстракции сервисов.

## Последствия

### Преимущества

1. **Безопасность**: Полное отсутствие сервера приложений исключает уязвимости серверного выполнения (RCE, SSRF, утечки памяти в Node.js рантайме).
2. **Производительность**: Статические файлы раздаются напрямую из edge-кэша CDN с географически ближайшего сервера к пользователю.
3. **Экономия ресурсов**: Нулевая стоимость поддержки серверов в простое, бесконечная горизонтальная масштабируемость при резких всплесках трафика.
4. **Предсказуемость тестирования**: Playwright E2E тесты тестируют именно те артефакты `out/`, которые отправляются в прод.

### Ограничения

- Нельзя использовать серверные обработчики Next.js API Routes (`app/api/*/route.ts`) с Node.js runtime.
- Интеграция с внешними сервисами (CRM, Google Forms, Telegram) перенесена в транспортную абстракцию `submitLead` либо внешние бессерверные функции.
