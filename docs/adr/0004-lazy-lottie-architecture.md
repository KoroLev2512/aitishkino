# ADR 0004: Архитектура ленивой загрузки анимаций (`LazyLottie`)

## Статус

Принято (Accepted)

## Контекст

В проекте используются 5 насыщенных векторных Lottie-анимаций. В исходном состоянии файлы JSON (`AdvantagesSection.json` 7.6 МБ, `secondblock.json` 9.7 МБ, `EarningSection.json` 4.9 МБ и др.) импортировались статически в шапках клиентских компонентов:

```tsx
import approachAnimation from '@/assets/animations/AdvantagesSection.json';
```

Это приводило к катастрофическим последствиям для производительности:

- Весь объем JSON (свыше 22 МБ исходного кода с сотнями встроенных base64-изображений) компилировался Webpack'ом в JS-чанк главной страницы;
- **First Load JS главной страницы составлял 15.1 МБ**;
- Время загрузки и парсинга скриптов на мобильных устройствах занимало десятки секунд, уничтожая показатели Core Web Vitals (LCP, TBT).

## Решение

Разработана архитектура отложенной загрузки `LazyLottie` (`src/components/ui/LazyLottie/LazyLottie.tsx`):

1. **Вынос тяжелых файлов из JS бандла**:
   - Все файлы анимаций перемещены в `public/animations/` и отдаются как обычные статические ресурсы по HTTP.
2. **Динамический импорт рантайма Lottie**:
   - Библиотека `lottie-react` загружается асинхронно через `next/dynamic` (`ssr: false`) только тогда, когда это действительно необходимо.
3. **Ленивая загрузка по IntersectionObserver**:
   - Анимации ниже первого экрана не запрашиваются из сети до тех пор, пока пользователь не доскроллит до области за 300px до компонента.
4. **Постер первого кадра для Hero-секции**:
   - Для Hero-анимации сгенерирован легковесный WebP постер первого кадра (1.8 КБ) с флагом `priority`, что обеспечивает мгновенную отрисовку без сдвигов верстки (CLS = 0).
5. **Поддержка `prefers-reduced-motion`**:
   - Если в операционной системе пользователя включен режим пониженного движения, тяжелые цикличные анимации не воспроизводятся, сохраняя статичный постер.

## Последствия

### Преимущества

1. **First Load JS страницы снизился с 15.1 МБ до 172 КБ (сокращение на ~99%)**.
2. Размер начального бандла самой страницы `/` составляет всего **62.8 КБ**.
3. На мобильных устройствах страница загружается практически мгновенно даже при медленном 3G/4G соединении.
4. Отсутствие сдвигов макета при подгрузке анимаций благодаря фиксированным размерам контейнеров и постерам.
